# Modelo de amenazas

Activos: NIE, identidad, autorizaciones, justificantes, tokens de sesión y facturación.

Amenazas: acceso no autorizado, filtración por logs, SSRF, XSS, CSRF, secuestro de sesión, duplicación de reservas, exfiltración de documentos, uso indebido del navegador remoto.

Controles: MFA, RBAC, cifrado de campos, HTTPS, CSRF, CSP, aislamiento por cliente, audit trail, límites de tasa, secret manager, escaneo de dependencias, backup cifrado, restauración probada.

Nunca subir secretos ni cookies al repositorio.
