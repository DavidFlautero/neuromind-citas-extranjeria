# Estrategia de pruebas

Unitarias: reglas y transiciones.
Integración: PostgreSQL, outbox, idempotencia.
Contrato: API OpenAPI.
E2E: portal ficticio con CAPTCHA simulado, errores, caducidad y confirmación.
Seguridad: permisos, aislamiento, secretos.
Caos: caída de worker, navegador y base de datos.
Nunca ejecutar pruebas automatizadas de carga contra el portal oficial.
